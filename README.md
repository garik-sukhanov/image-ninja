# Image Ninja

Локальный редактор изображений и SVG для macOS на Electron + React + TypeScript.
Всё считается на машине: ни одно изображение никуда не отправляется.

**Растр:** обрезка, цветокоррекция, удаление фона (волшебная палочка, кисть,
нейросеть офлайн), экспорт в PNG / JPEG / WEBP / AVIF / TIFF.
**SVG:** редактор, где источник истины — сам файл, поэтому он не теряет
`clipPath`, `filter`, `<style>` и вложенные группы; слои, узлы, булевы
операции, автовекторизация растра.

## Быстрый старт

Нужны macOS и Node.js 20.9 или новее.

```bash
git clone https://github.com/garik-sukhanov/image-ninja.git
cd image-ninja
npm install
npm run dev
```

Подробности по командам и сборке `.app` / `.dmg` — в разделе «Команды» ниже.

## Стек

- **Electron 38** + **electron-vite** — main / preload / renderer
- **React 18** + **TypeScript** + **Tailwind CSS** + **Zustand**
- **sharp** (libvips) — декод/энкод PNG, JPEG, WEBP, AVIF, TIFF, HEIC; альфа-канал
- **svgo** — оптимизация SVG на экспорте
- **svg-path-commander** — разбор и нормализация `d`, конвертация фигур в контуры
- **perfect-freehand** — карандаш с нажимом
- **polygon-clipping** — булевы операции над контурами
- **magic-wand-tool** — заливка по цвету для «волшебной палочки»
- **onnxruntime-node** + U²-Net / IS-Net — вырезание фона нейросетью, офлайн
- **@neplex/vectorizer** (VTracer) — автоматическая векторизация растра

## Режим разработки

```bash
npm run dev
```

Vite поднимает renderer на `http://localhost:5174`, компилит `electron/` в `out/`
и запускает Electron. `src/` обновляется по HMR, `electron/` перезапускает
процесс сам. Если не подхватилось — `Cmd+R` в окне.

## Что умеет

### Для всех изображений

- **Обрезка** — свободная и по пресетам (1:1, 4:3, 3:2, 16:9 и зеркальные),
  ручки по краям и углам, сетка третей, числовые поля. Неразрушающая: рамку
  можно поменять или снять в любой момент.
- **Цветокоррекция** — экспозиция, яркость, контраст, гамма, насыщенность,
  сочность, оттенок, температура, тон, резкость, размытие, Ч/Б, инверсия.
  Кнопка «Авто» тянет уровни по гистограмме с отсечкой 0.5 %.
- **Альфа-канал** — общая непрозрачность и порог отсечки, который обнуляет
  почти прозрачные пиксели и убирает ореол по краю выреза.
- **Поворот и отражение** — шаг 90°, отражение по обеим осям. Маска выреза
  поворачивается вместе с картинкой.
- **Экспорт** — PNG, JPEG, WEBP, AVIF, TIFF; масштаб или точный размер,
  качество, подложка вместо прозрачности, оценка веса файла до сохранения.
- **Векторизация** — «Преобразовать в SVG» обводит то, что на холсте: с
  обрезкой, вырезанным фоном и цветокоррекцией. Результат открывается новым
  SVG-проектом, растровый остаётся на месте.

### Удаление фона

Три способа, они складываются друг с другом в одну маску:

- **По клику** — волшебная палочка: допуск, растушёвка, расширение/сжатие
  выделения, режим «только смежная область» или «все похожие пиксели».
  Alt при клике возвращает область вместо удаления.
- **Вручную** — ластик и кисть восстановления: размер, жёсткость, нажим.
  `[` и `]` меняют размер.
- **Нейросетью** — U²-Net Lite (4 МБ), U²-Net (168 МБ) или IS-Net (170 МБ).
  Модель качается один раз и дальше работает офлайн; порог и смягчение края
  настраиваются.

Переключатель «Подсветить удалённое» заливает вырезанное красным, чтобы было
видно, что именно ушло.

### SVG-редактор

Главное отличие от редакторов на canvas (fabric.js, paper.js, konva): здесь
**источник истины — сам SVG**. Сцена рендерится настоящими SVG-элементами, а в
модели лежат атрибуты как есть. Поэтому файл переживает круг «открыл →
поправил → сохранил» без потерь: `clipPath`, `filter`, `symbol`, `<style>`,
`xlink:href`, `data-*`, вложенные группы с трансформами и `tspan` внутри
`<text>` остаются на месте.

- **Выделение и трансформации** — клик, Shift для добавления, рамка выделения,
  8 ручек масштаба и ручка поворота. Ручки живут в экранных пикселях и
  обнимают повёрнутый объект, а не его габаритный прямоугольник.
- **Привязки** — к краям и центрам других объектов и к артборду, плюс сетка.
  Оранжевые направляющие показывают, к чему прилипло. Alt при перетаскивании
  отключает привязку.
- **Узлы** — таскание точек и безье-ручек, Alt по узлу переключает
  «угол ↔ гладкий», клик по контуру вставляет узел, Delete удаляет. Примитивы
  (`rect`, `circle`, `polygon`, …) конвертируются в `<path>` при первой правке
  узлов; прямые сегменты, которых не касались, возвращаются в файл как `L`, а
  не как вырожденные кривые.
- **Рисование** — перо (с замыканием контура), карандаш на perfect-freehand,
  прямоугольник, эллипс, линия, многоугольник, звезда, текст с правкой на
  месте.
- **Слои** — дерево с группировкой, z-порядком, переименованием, замком и
  скрытием. Скрытые слои не удаляются при экспорте, а уезжают с `display:none`.
  Порядок меняется перетаскиванием: линия показывает место вставки, а средняя
  треть строки группы кладёт слой внутрь неё. При смене родителя `transform`
  пересчитывается, поэтому объект не съезжает на экране ни на пиксель.
- **Контекстное меню** по правой кнопке — на холсте и в списке слоёв: выше,
  ниже, на передний и задний план, дублировать, группировка, преобразовать в
  контур, скрыть, заблокировать, удалить.
- **Подложка** — референс под холстом: непрозрачность, вписать / 1:1 / по
  холсту, числовые поля, блокировка. Разблокированную можно таскать мышью.
  В экспорт не попадает никогда.
- **Автовекторизация** — VTracer обводит подложку и кладёт результат группой
  ровно по её рамке. Цветной и Ч/Б режимы, сплайны / полигоны / пиксели,
  фильтр крапинок, точность цвета, слияние слоёв. Фоновый контур на всю
  картинку (то самое белое полотно под логотипом) выбрасывается автоматически.
- **Цвета документа** — все литеральные цвета файла с подсчётом использований и
  заменой одним кликом по всему документу разом, включая `<style>` и
  внутреннюю разметку. Это самый быстрый способ перекрасить чужую иконку.
- **Булевы операции** — объединение, вычитание, пересечение, исключение.
- **Выравнивание и распределение** по обеим осям.
- **Панель кода** — живой исходник файла; можно править руками или вставить
  чужой SVG целиком и нажать «Применить». Кнопка `svgo` показывает, сколько
  ужалось, до применения.
- **Экспорт** — SVG (с svgo или без) и растр в любом из поддерживаемых
  форматов; растеризацией занимается сам Chromium, поэтому что на холсте, то и
  в файле.

## Горячие клавиши

**Общие:** `Cmd+S` сохранить · `Cmd+E` экспорт · `Cmd+Z` / `Cmd+Shift+Z`
отмена и повтор · `0` вписать · `1` масштаб 100 %

**Растр:** `V` перемещение · `C` обрезка · `W` палочка · `E` ластик ·
`R` восстановление · `I` пипетка · `[` `]` размер кисти · `Enter` применить
обрезку

**SVG:** `V` выделение · `A` узлы · `P` перо · `B` карандаш · `R` прямоугольник ·
`O` эллипс · `L` линия · `G` многоугольник · `S` звезда · `T` текст · `H` рука ·
пробел — временная панорама · `Cmd+G` / `Cmd+Shift+G` группировка ·
`Cmd+D` дублировать · `Cmd+]` / `Cmd+[` выше и ниже (с Shift — на передний и
задний план) · стрелки — сдвиг на 1 px, с Shift на 10

## Как это устроено

```
electron/
  main.ts            окно, протокол imgfile://, диалоги
  ipc/image.ts       sharp: probe, подготовка к показу, энкод, оценка веса
  ipc/svg.ts         чтение/запись SVG, svgo
  ipc/segment.ts     onnxruntime: реестр моделей, догрузка, инференс
  ipc/vector.ts      VTracer: растр → SVG на воркер-потоке napi
  ipc/projects.ts    проекты в userData: project.json, meta.json, mask.png
src/
  raster/
    pipeline.ts      вся пиксельная математика (LUT, цвет, размытие, резкость)
    compose.ts       сборка документа: кроп → маска → пайплайн
    selection.ts     волшебная палочка, растушёвка, кисть
    orient.ts        поворот/отражение картинки и маски согласованно
  svg/
    parse.ts         SVG → сцена (неизвестное сохраняется как есть)
    serialize.ts     сцена → SVG
    geometry.ts      матрицы и bbox через собственный движок браузера
    path.ts          узлы, безье-ручки, вставка/удаление точек
    transform.ts     применение трансформации с учётом родительских групп
    trace.ts         векторизация и вставка результата в документ
    boolean.ts       флаттеринг кривых + polygon-clipping
```

Два принципа, на которых всё держится:

1. **Превью и экспорт считает один и тот же код.** `applyAdjustments` работает
   и на превью, и на полном разрешении — отличается только масштаб. Поэтому
   «на экране одно, в файле другое» здесь структурно невозможно.
2. **Геометрию SVG считает браузер.** `getBBox()` и `getScreenCTM()` дают
   точные габариты для текста, обводок и любых контуров — переписывать это
   вручную значит гарантированно расходиться с тем, что видит пользователь.

### Модель для удаления фона

По умолчанию модель качается по требованию в
`~/Library/Application Support/image-ninja/models/`. Чтобы вшить её в `.app`:

```bash
npm run prepare:model u2netp
npm run dist
```

Без модели всё остальное работает: палочка и кисть ничего не качают.

## Проверка

Типы:

```bash
npm run typecheck
```

Сквозная проверка гоняется через CDP по запущенному приложению: создаются
проекты, кликается UI, читаются пиксели с холста и сериализованный SVG.
Покрыто: рендер сцены, выделение, перетаскивание, ресайз ручкой, правка узлов,
рисование, отмена, круговой обход SVG со сложным файлом, замена цвета,
палочка, ластик, обрезка, цветокоррекция, оценка веса, энкод через sharp,
инференс ONNX, перетаскивание слоёв (включая перенос в группу с проверкой, что
объект не сдвинулся), контекстное меню, подложка и обе точки входа
векторизации.

## Ограничения

- Булевы операции превращают кривые в полигоны — это неизбежно при клиппинге
  полигонов, так же ведут себя и другие редакторы.
- Резкость и размытие отключаются на время мазка кистью и возвращаются после
  отпускания: они дороже всего остального пайплайна вместе взятого.
- `fit` не увеличивает изображение крупнее 100 % — маленькая картинка
  показывается пиксель в пиксель, а не растянутой на весь холст.
- Векторизация уменьшает исходник до 2048 px по длинной стороне: выше этого
  растёт только число контуров, а не различимая детализация. Сам вектор
  остаётся масштабируемым.
- Подложка хранится ссылкой на файл, а не копией. Если файл переехать —
  проект откроется, но подложка будет пустой, о чём приложение скажет.
